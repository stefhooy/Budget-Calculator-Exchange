# Budget Calculator & Exchange Rate Tracker [2026]

> Originally built in 2024 — remastered in 2026 with a cleaner structure and improved code.

## Overview

A personal finance tool that tracks spending across Europe and calculates budget breakdowns with real exchange rate data. Built as a personal project during the Winter 2024 term at IE University.

## Project Structure

```
Budget-Calculator-Exchange/
├── src/                        # Source code
│   ├── budgetcalculator2024.py     # Core budget calculator script
│   └── PersonalProject2.ipynb      # Jupyter notebook with full analysis
├── data/                       # Data & outputs
│   ├── statswinter24.csv           # Raw spending data (Winter 2024)
│   └── europespending2024.html     # Interactive spending visualization
└── README.md
```

## How to Run

1. Make sure you have Python and Jupyter installed.
2. Open `src/PersonalProject2.ipynb` in Jupyter for the full walkthrough.
3. Or run the standalone script directly:
   ```bash
   python src/budgetcalculator2024.py
   ```
